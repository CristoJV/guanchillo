# Plan 001 · Editor and stitch tracking

The MVP covers a pattern library, grid editing, a palette, undo and redo, JSON import and export, and a follow mode that supports broad click targets and keyboard input.

1. Set up the repository, documentation and static web entry point.
2. Implement pattern editing, color counts and the library.
3. Implement stitch tracking, configurable direction and resumption.
4. Verify persistence, keyboard and touch interaction, and large patterns.

The [architecture guide](../technical/architecture.md) documents the data and implementation. Future image conversion is proposed in [RFC 001](../rfcs/001-import-image.md).
